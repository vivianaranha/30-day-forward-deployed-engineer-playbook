# Requirements

## Functional
1. Accept subject and description.
2. Classify category.
3. Estimate priority.
4. Produce a concise summary.
5. Recommend responsible team.
6. Expose results through an API.
7. Provide a simple UI.
8. Preserve original ticket ID.

## Nonfunctional
- Response under 3 seconds in demo mode.
- Invalid input fails safely.
- No secrets in source code.
- High-priority tickets clearly identified.
- API exposes health status.
- Business logic testable independently.
