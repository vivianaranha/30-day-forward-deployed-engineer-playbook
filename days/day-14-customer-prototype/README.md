# Day 14: Build the Customer-Facing Prototype

## Objective
Create a usable experience quickly.

## Hands-On Challenge
Run Streamlit and test the end-to-end workflow.

## FDE Questions
- What customer problem does this solve?
- What evidence supports the decision?
- What is the simplest solution?
- What could fail?
- What does the customer need to own?
- How will value be measured?

## Deliverable
Create or update one concrete engagement artifact.

## Definition of Done
- The artifact exists.
- The decision can be explained to a customer.
- At least one trade-off is documented.
- The work connects to a measurable outcome.
