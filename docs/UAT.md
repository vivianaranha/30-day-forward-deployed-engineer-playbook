# User Acceptance Testing

## Scenarios
1. Normal authentication ticket
2. Billing ticket
3. High-impact network ticket
4. Critical outage
5. Ambiguous ticket
6. Very short description
7. Unsupported category
8. Integration failure
9. Duplicate submission
10. Feedback submission

Ask whether the recommendation is understandable, trustworthy, correctly routed, correctly prioritized, and useful.
